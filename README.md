# AsterAletheia

**Open Observatory & Reality Traceability System**

> 「データを保存する」のではなく、「現実世界の事象から科学的真実に至るまでの過程（証明）を保存する」

光学・電波・気象など異分野の観測を一つの事象モデルで統合し、検証可能な信頼の起点から論理的な証明までを一気通貫でつなぐ観測プラットフォーム。

**現状:** 設計段階（M0）。実装コードは未着手。設計は特定の実装技術・言語・規格から切り離して定義している。

## 一文

すべての結論に「物理現象の発生から主張に至るまでの因果と前提の連鎖」を証明木として添え、誰でも機械的に検証・追試できるようにする。

## 3 つのパラダイムシフト

1. **対象中心から事象中心へ** — 「変光星用」「流星用」の縦割りをやめ、すべてを時空間で起きた物理信号として扱う
2. **検証可能な信頼の起点** — 未知の遅延や内部処理がないことを、公開された設計で自ら担保する
3. **観測の形式手法** — 補正の過程を型と系譜グラフで管理し、前提を満たさない限り科学的主張を出せない

## 8 つのスコープ

| ID | スコープ | 役割 |
|----|----------|------|
| S8 | 人間中心の発見・知識探求 | 異常・周期・相関に人間が「気づく」ための探索とオープンサイエンス |
| S7 | 分散協調・立体観測ネットワーク | 地上・移動・成層圏拠点を束ねた立体的な合成観測 |
| S6 | 科学的主張・形式的検証 | Claim と Proof Tree の構築、自動査読 |
| S5 | 形式的解析・系譜追跡 | 段階的な誤差剥離、観測の型制約、系譜と再計算性 |
| S4 | 観測記録・不変データ基盤 | マルチモーダルな観測セッションの不変記録 |
| S3 | ノード自律制御・事象駆動ランタイム | 状態機械・異分野トリガー・安全縮退 |
| S2 | 物理計測・信頼起点 | 時空間の不確かさの獲得、透明なセンサー、自己校正 |
| S1 | 統合理念・存在論 | 事象中心モデル、6DoF 観測者、現実トレーサビリティ |
