# AsterAletheia

**Open Observatory & Reality Traceability System**

> **個人でも研究機関レベルの観測環境を構築できる世界へ。**

核は、**現実世界を観測・記録・検証するための汎用知識基盤**。その最初の応用が、高精度・高信頼な観測を誰でも行えるオープンサイエンス基盤であり、最初の題材が天文学である。観測装置も、ソフトウェアも、データも、解析手順も開放する。

```text
世界 ⇢ 観測 → 測定 → 主張 ⇢ 知識 ⇢（予測）⇢ 世界
```

設計は一番下の「この世界で何が存在するのか」から積み上げる（[存在論の階層](internal/docs/ONTOLOGY.md)）。

**現状:** 設計段階（M0）。実装コードは未着手。設計は特定の実装技術・言語・規格から切り離して定義している。

## 一文

「データを保存する」のではなく、「現実世界の事象から科学的真実に至るまでの過程（証明）を保存する」。すべての結論に因果と前提の連鎖を証明木として添え、誰でも機械的に検証・追試できるようにする。

## 5 本柱

| 柱 | 開くもの |
|----|----------|
| Observatory Hardware | 高精度かつ再現可能な観測機材の設計（時刻基準・測定カメラ・全天観測・電波観測・気象観測・移動観測キット） |
| Observatory OS | 観測拠点で動くソフトウェア |
| Observatory Network | 世界中の個人観測所をつなぐ協調観測網 |
| Science Data Platform | データ・解析手順・検証可能な科学的主張 |
| Research Community | 誰でも参加でき、追試できる研究の場 |

5 本柱を貫く背骨が **Reality Traceability**（証明の連鎖）である。

## 3 つのパラダイムシフト

1. **対象中心から事象中心へ** — 「変光星用」「流星用」の縦割りをやめ、すべてを時空間で起きた物理信号として扱う
2. **検証可能な信頼の起点** — 未知の遅延や内部処理がないことを、公開された設計で自ら担保する
3. **観測の形式手法** — 補正の過程を型と系譜グラフで管理し、前提を満たさない限り科学的主張を出せない
