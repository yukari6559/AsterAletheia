# HARDWARE — Observatory Hardware の考え方と機材ファミリー

5 本柱の一つ **Observatory Hardware** の正本。責務の上では主に [S2](scopes/S2-measurement-root-of-trust.md) にあたる。  
ここでは役割・観測対象・要求水準だけを定め、部品や方式は定めない（技術中立）。

---

## 1. 目標

**高精度かつ再現可能な観測機器を、公開された設計として開く。**

重要なのは「綺麗な写真」ではなく **「測定可能なデータ」** を得ることである。機材の価値は、出力の見た目ではなく、どれだけ強い信頼の根拠と小さな不確かさで物理量を渡せるかで決まる。

## 2. 機材はモジュールの合成

```text
観測機材 ＝ センサー ＋ 制御 ＋ 時刻 ＋ 通信 ＋ …（モジュール）
観測拠点 ＝ 観測機材の集まり（時刻モジュールは共有できる）
```

| モジュール | 役割 | 主に関わるスコープ |
|------------|------|--------------------|
| センサー | 物理量を、勝手な補正なしに生信号へ変える | S2 |
| 制御 | 機器の設定と状態監視（制御経路） | S2 / S3 |
| 時刻 | 信号に時刻と不確かさを刻む | S2 |
| 通信 | 記録と証明情報を拠点の外へ運ぶ（遅延同期を含む） | S4 / S7 |

### モジュール契約

すべてのモジュールは、作り手に関わらず同じ契約で接続する（[D-17](DECISIONS.md)）。

| 契約の要素 | 内容 |
|------------|------|
| 制御経路 | 設定・状態監視の口 |
| データ経路 | 生信号を遅延なく流す口（制御経路と分ける） |
| 信頼の根拠の宣言 | 同期の基準、内部処理の透明性、遅延の既知性 |
| 設計の版への参照 | 公開設計なら、その版を内容の要約で指す（[D-19](DECISIONS.md)） |

- 自作・公開設計・市販品の違いは **宣言される信頼の根拠の違いだけ**。だから部品単位で交換でき、望遠鏡 A ＋カメラ B ＋架台 C ＋自作装置 D の組み合わせでも統合運用できる。ベンダーロックインの排除は、この契約の帰結である。
- 機材の信頼の根拠は構成モジュールから合成され、ある証明に関わるモジュールのうち最も弱い根拠を超えない。
- 同じ拠点の機材が時刻モジュールを共有すれば、拠点内の異分野の信号が **同じ時刻の根拠** を持つ。クロスモーダル連動（S3）と異分野の重ね合わせ（S8）の土台になる。

## 3. 機材ファミリー

| ファミリー | 役割 | 主な観測対象 | 重視する性質 |
|------------|------|--------------|--------------|
| **時刻基準** | 全機材に共通の信頼の起点（[D-18](DECISIONS.md)） | ―（すべての観測の時刻） | 時刻の不確かさの小ささと、その根拠の検証可能性 |
| **測定カメラ** | 光の量と位置を測る | 系外惑星、変光星、掩蔽 | 線形性、ダイナミックレンジ、露光タイミングの厳密さ |
| **全天観測** | 空全体を 24 時間自動で見張る | 流星、火球、人工衛星、雲量 | 無人での連続運用、突発事象の検知 |
| **電波観測** | 電波の振幅・位相・周波数を測る | 太陽電波、水素線、流星散乱、人工衛星 | 生の信号の保存、基準信号による校正 |
| **気象観測** | 観測の文脈であり、それ自体が観測でもある（[D-20](DECISIONS.md)） | 気温、湿度、風、雲量、空の明るさ | 環境の証明と大気補正の根拠になる精度 |
| **移動観測キット** | 遠征して観測する一式 | 掩蔽 | 持ち運び、観測者の軌跡の記録（S1）、オフラインでの完結（S4） |

### 時刻基準が最重要である理由

研究水準の観測では、時刻が結果の信頼を左右する（掩蔽、流星の多点観測、電波の到来時刻など）。時刻モジュールは全ファミリーで共通なので、これを改善すると全機材の主張できる範囲が同時に広がる。  
**目標水準:** 個人がナノ秒〜マイクロ秒級の時刻情報を、根拠付きで扱える状態。実現方式は定めない。

## 4. 一つの事象を、複数のファミリーで見る

事象中心（S1）なので、一つの現象は複数の機材ファミリーから同時に観測される。機材は対象別の道具ではなく、事象への異なる窓である。

| 事象の例 | 時刻基準 | 測定カメラ | 全天観測 | 電波観測 | 気象観測 | 移動キット |
|----------|:--------:|:----------:|:--------:|:--------:|:--------:|:----------:|
| 流星・火球 | ● | | ● | ●（散乱） | ●（文脈） | |
| 人工衛星 | ● | ● | ● | ● | | |
| 掩蔽 | ● | ● | | | ●（文脈） | ● |
| 変光星・系外惑星 | ● | ● | ●（雲量） | | ●（文脈） | |
| 太陽 | ● | | | ● | ● | |
| 雲・大気 | ● | | ● | | ● | |

● は主な観測、（ ）は役割の補足。
