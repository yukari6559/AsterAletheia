# Scope 3：ノード自律制御・事象駆動ランタイムスコープ

**【役割】単一の観測拠点（地上・移動体・高高度）において、計画および突発事象に応じた観測の遂行と自己保全を司る実行環境層**

人間の常時監視を前提とせず、与えられた目的や目の前で起きた現象に対して、観測拠点が自律的に判断・行動するための制御領域。

| 入力 | 内部で保証・変換すること | 出力 |
|------|--------------------------|------|
| 観測計画・リアルタイム生信号 | 状態遷移・異分野トリガー連動・安全縮退制御 | 自律的な機器制御とイベント検知トリガー |

---

## 1. 状態機械による観測ライフサイクル管理

- 待機、準備、機器校正、対象導入、計測実行、データ検証、退避といった観測の一連の振る舞いを厳密な状態遷移として管理する。
- 中途半端な状態でのデータ取得や機器の暴走を防ぐ。

## 2. 計画駆動と事象駆動（リアクティブ制御）の融合

- 「指定された時刻・高度に達したら観測を開始する」というスケジュール駆動だけでなく、異なる分野のセンサー間で連鎖反応を起こす「クロスモーダル・トリガー」を処理する。
- 例：「広角の光学センサーが突発的な閃光を検知した瞬間、電波センサーの過去数分間の循環バッファを保護領域へロックし、高倍率センサーの記録レートを最大化する」といったリアルタイム連動を司る。

## 3. リアルタイム品質監視とフィードバック

- 観測終了を待たずに、流入する生信号から「追尾のズレ」「ピントの劣化」「雲の侵入」「信号の飽和」などを即座に検知する。
- 再調整の実行やデータへの警告フラグ付与をその場で行う。

## 4. 環境適応と自律的縮退運転（サバイバビリティ）

- 気象悪化時の物理的な機材保護（ドーム閉鎖や電源遮断）を行う。
- 移動観測や成層圏気球などの過酷な環境において、バッテリー残量、内部温度、通信帯域、ストレージ残量に応じて「どの計測を維持し、どの処理を間引くか」を自律的に判断する。
