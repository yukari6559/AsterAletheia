# TS-0001 時刻モジュールの基準機（T0・T1）

| 項目 | 内容 |
|------|------|
| 状態 | **採用**（2026-10-19） |
| 満たす要求 | [TIMING-MODULE](../hardware/TIMING-MODULE.md) の T-R1・T-R2・T-R3・T-R6・T-R7（T-R4 の保持は T2 で扱う） |
| 対象段階 | T0（基準機）、T1（FPGA タイムスタンプ） |

---

## 候補と比較

### 基準（GNSS 受信モジュール）

| 候補 | 長所 | 短所 |
|------|------|------|
| **汎用の GNSS モジュール**（時刻パルス出力付き） | 安い（数千円）、入手しやすい | 時刻パルスの精度は製品依存。誤差の補正情報が出るかは製品の資料で確認が要る |
| タイミング用の GNSS モジュール | 時刻パルスが高精度、誤差の補正情報が出る、位置を固定して時刻だけを解く動作がある | 高い（1 万〜数万円） |

T1 の不確かさは FPGA の刻みの粗さ（100 ナノ秒級）が支配的なので、T0・T1 では汎用品で足りる。タイミング用は、基準の誤差そのものを補正する T3 で別の記録（後継 TS）として選ぶ。

### タイムスタンプを付ける部品

| 候補 | 長所 | 短所 |
|------|------|------|
| **手持ちの FPGA ボード（Tang Primer 25K）** | 追加費用なし。SharpHdl で記述でき、回路が公開・検証できる。後の受信機・カメラ読み出しにも使える | 入出力の電圧と端子の割り当てを確認する必要がある |
| マイコンの捕捉機能 | 手軽 | 刻みが粗く、処理の割り込みが遅延に入りやすい。回路として検証しにくい |

### 計算機への経路

GNSS モジュールの状態情報と FPGA の時刻記録は、どちらもシリアル通信で計算機へ送る。時刻は計算機に届く前に付いているので、この経路の遅延は不確かさに入らない（T-R7）。

### アンテナ

空がよく見える場所に置ける、電源供給型の GNSS アンテナ。アンテナ線の長さは記録しておく（T3 で経路の遅延として校正する）。

## 選定

| 部品 | 採用 |
|------|------|
| 基準 | 汎用の GNSS モジュール（時刻パルス出力付き）＋ GNSS アンテナ |
| タイムスタンプ | Tang Primer 25K（SharpHdl で回路を記述する） |
| 計算機への経路 | シリアル通信 |

確認の状況:

| 項目 | 状況 |
|------|------|
| FPGA の入力電圧 | 確認済み。拡張端子（PMOD）は 3.3 V 系の入出力 |
| GNSS モジュールの時刻パルスの電圧 | **購入時に確認**。3.3 V 系の論理で時刻パルスを出す製品を選ぶ（5 V 系なら電圧変換が要る） |
| ボード上の発振器の周波数 | 確認済み。50 MHz（刻み 20 ns） |
| ボード上の発振器の精度 | 資料では未確認。T1 で、時刻パルス間の計数値から実測する |
| T1 の回路（計数器・非同期入力の取り込み・ラッチ・シリアル出力）を SharpHdl で書けるか | T1（#10）で確認。足りない機能は SharpHdl 側の Issue にする |

### 刻みから見た T1 の見積もり

刻みは 20 ns なので、刻みの粗さによる誤差は 1 刻み以内（20 ns）に収まる。非同期入力の取り込みによる遅延は数刻み分で一定なので、校正値として差し引ける。T1 の不確かさの目安（100 ナノ秒級）は、この刻みに基準の誤差と発振器のふらつきを合わせたものである。

参照: [Sipeed Wiki: Tang Primer 25K](https://en.wiki.sipeed.com/hardware/en/tang/tang-primer-25k/primer-25k.html)、[Tang Primer 25K Specification v1.0](https://akizukidenshi.com/goodsaffix/Tang_Primer_25K_Specification_V1.0_en.pdf)

## 宣言する信頼の根拠

| 分かること | 分からないこと（次の自作候補） |
|------------|--------------------------------|
| FPGA の刻みの粗さ（20 ns）、入力回路の遅延（T1） | GNSS モジュール内部の時刻パルス生成の誤差（T3 でタイミング用と比べる） |
| ボード上の発振器の精度（T1 で実測） | |
| 回路の設計（SharpHdl のソースと版） | ボード上の発振器の基準間のふらつき（T2 で自作の発振器同期と比べる） |
| | 相手機材（カメラ・受信機）が事象の信号を出すまでの内部遅延（各機材の自作で置き換える） |
