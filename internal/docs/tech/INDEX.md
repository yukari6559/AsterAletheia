# tech — 技術選定記録

部品・方式・技術の選定を残す場所（[D-34](../DECISIONS.md)）。設計は技術中立のまま保ち、技術は設計要求に従属させる。

## 書式

各記録は `TS-xxxx-<短い名前>.md` とし、次の項目を持つ。

| 項目 | 内容 |
|------|------|
| 状態 | 提案 ／ 採用 ／ 置換（置換時は後継の TS を示す） |
| 満たす要求 | どの設計要求（例: T-R1）のための選定か |
| 候補 | 比べた選択肢 |
| 比較 | 要求に対する長所・短所、費用、入手性、公開性（設計が検証できるか） |
| 選定 | 選んだものと理由 |
| 宣言する信頼の根拠 | この選定で分かること・分からないこと（分からないことは次の自作候補） |

状態が「提案」の記録は、ユーザーが決めた時点で「採用」に変える。
