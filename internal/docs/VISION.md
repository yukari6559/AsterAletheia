# VISION — 全体設計とスコープ構造

本プラットフォームの全体設計を、特定の実装技術・言語・規格から完全に切り離し、「概念・機能・責務のスコープ（領域）」ごとに分割して定義する。

全体は、物理世界の事象を捉える最下層から、科学的真実の証明と人間の発見を支援する最上層まで、明確に責務が分離された **8 つのスコープ** によって構成される。

各スコープの詳細は [`scopes/`](scopes/) を正本とする。

│ [Scope 5] 形式的解析・系譜追跡スコープ                                  │

|----|----------|--------------|------|

## スコープ間の責務境界まとめ

| スコープ | 入力されるもの | 内部で保証・変換すること | 出力されるもの |
| --- | --- | --- | --- |
| **1. 統合理念・存在論** | 現実世界のあらゆる現象 | 事象・6DoF観測者・証明の概念定義 | 全スコープ共通の概念体系（Ontology） |
| **2. 物理計測・信頼起点** | 物理現象（光・電波・環境・時間） | 時空間の不確かさ定量化・線形取得・自己校正 | 物理的信頼が保証された生信号ストリーム |
| **3. ノード自律制御** | 観測計画・リアルタイム生信号 | 状態遷移・異分野トリガー連動・安全縮退制御 | 自律的な機器制御とイベント検知トリガー |
| **4. 観測記録・不変基盤** | 複数ストリーム・環境・機器状態 | マルチモーダル束ね・不変性（改ざん防止）付与 | 自己完結した不変の「観測セッション記録」 |
| **5. 形式的解析・系譜** | 不変の観測セッション記録 | 型制約による誤処理防止・段階的誤差剥離・系譜記録 | 系譜（Provenance）が保証された物理指標 |
| **6. 科学的主張・検証** | 物理指標・系譜・校正/環境記録 | 前提条件の網羅的検査・証明木の構築・自動査読 | 数学的・論理的に検証済みの「科学的主張」 |
| **7. 分散協調・立体網** | 各拠点の主張・観測セッション | 多点スケジュール配分・立体三角測量・大気差分 | 地球規模・立体空間で統合された合成観測知見 |
| **8. 人間中心の発見** | 統合知見・長期アーカイブ | 異分野相関の可視化・異常や周期のハイライト | 人間による「未知の発見」と新たな研究仮説 |

## 設計上の原則

- **技術中立:** 本設計は概念・機能・責務のみを定義する。実装技術・言語・規格は各スコープの定義が固まった後、根拠を残して選定する。
- **責務の一方向性:** 各スコープは下位スコープの出力を入力とし、上位スコープへ出力を渡す。境界は上表を正とする。
- **S1 は全スコープの共通語彙:** 事象・観測者（6DoF）・現実トレーサビリティの概念は、すべてのスコープで同じ意味で使う（[GLOSSARY](GLOSSARY.md)）。
