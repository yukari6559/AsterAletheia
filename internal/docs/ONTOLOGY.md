# ONTOLOGY — 存在論の階層（Level 0–8）

設計を上からではなく、一番下の「この世界で何が存在するのか」から積み上げるための正本。[S1](scopes/S1-ontology.md) の詳細にあたる。

- 8 スコープは **責務**（誰が何に責任を持つか）を分ける。本書は **概念**（何が存在するか）を積む。
- 本書は概念だけを定める。データ構造・型名・保存形式は定めない（技術中立）。
- 判断の経緯は [DECISIONS](DECISIONS.md) の D-22〜D-31。

## 積み上げの規則

1. **各レベルは、自分より下のレベルの概念だけで定義する**（[D-23](DECISIONS.md)）。
2. Level 0 は種類と関係だけを置く。属性は上のレベルが一段ずつ与える。
3. 「天体」などの分野の概念は、Level 7 まで登場しない。

```text
Level 8  知識      Theory — Claim を説明し、事象を予測する仮説（支持・反証される）
Level 7  科学      分野別の手法：信号処理 → 推定 → 主張
Level 6  来歴      節点（Observation・Measurement・Claim）と辺（Transformation）、Proof
Level 5  観測      Observation — 世界と認識の唯一の接点
Level 4  信号      Signal — 軸の組の上に並んだ推定量
Level 3  空間      位置推定（位置・速度・姿勢・方向）
Level 2  時間      観測時刻・観測区間
Level 1  推定量    値・不確かさ・確信度・参照系・来歴
Level 0  世界観    世界／境界／認識、Entity・Event
```

## Level 0 — 世界観

このシステムにおいて存在するものを、三つの区分に分ける（[D-24](DECISIONS.md)）。

| 区分 | 含むもの | 性質 |
|------|----------|------|
| **世界**（Reality） | Entity、Event | 直接には触れられない。認識の側には推定としてのみ現れる |
| **境界** | Observation | 世界が観測者に残した痕跡。世界と認識の唯一の接点 |
| **認識** | Measurement、Transformation、Claim、Proof、Theory | すべて観測から導かれる |

### Entity（存在物）

- Entity は **分類を持たない**。「恒星」「流星」「人工衛星」「電波源」「気温」を特別な型として置かない（[D-25](DECISIONS.md)）。
- 存在物は、知り方によって二つに分かれる。

| 知り方 | 例 | どう知るか |
|--------|-----|------------|
| **宣言される存在** | 観測者、センサー、モジュール | システム自身が信頼の根拠とともに宣言する。状態は推定量として持つ |
| **推定される存在** | 恒星、小惑星、人工衛星、大気 | 同定 Claim を通じてのみ知られる |

### Event（事象）

- 世界で起きたこと。「何かが起きた」以上の分類を持たない。
- 例: 星が発光した、流星が燃えた、衛星が通過した、太陽フレアが発生した。これらの文に含まれる「星」「流星」も、同定 Claim によるラベルである。
- 世界のモデルの単位は事象である。ただしシステムが事実として持つのは観測だけであり、**事象の存在もまた Claim** として推定される。

### Observation と Event は違う

**実際の星** と **カメラに映った星** は違う。ここが科学の出発点である。

## Level 1 — 推定量

完全な値は観測できない。したがって、このシステムに **素の値は存在しない**（[D-26](DECISIONS.md)）。

```text
普通のシステム      値
このシステム        値 ＋ 不確かさ ＋ 確信度 ＋ 参照系 ＋ 来歴
```

| 構成 | 意味 |
|------|------|
| 値 | 最もありそうな値 |
| 不確かさ | 値の広がり |
| 確信度 | 不確かさの表明そのものがどれだけ信頼できるか。信頼の根拠（[S2](scopes/S2-measurement-root-of-trust.md)）から決まる |
| 参照系 | 値が何に対して測られているか（時刻系、座標系、単位系など） |
| 来歴 | どこから来たか（時刻の源も、位置の導出も来歴の一種） |

- 同じ「± 500 ns」でも、根拠の強い時刻基準と内部処理の分からない機材とでは確信度が違う。
- 不確かさは変換ごとに伝播し、消えない（[D-07](DECISIONS.md)）。

## Level 2 — 時間

このプロジェクトでは、天文学より時間が重要である。

- **観測時刻**（Observed Instant）: 時刻の推定量。完全な時刻（時点）は観測できないので、時点そのものは置かない。
  - 例: 12:00:00.123456789 ± 500 ns（源: 時刻モジュール、参照系: ある時刻系）
- **観測区間**: 開始と終了の観測時刻の組。露光やサンプリングは幅を持つので、観測は時点ではなく区間を持つ。
- 時刻の扱いは最初から体系の中心にあり、上がっていくのは精度である（[D-18](DECISIONS.md)）。
- 時刻の不確かさは一定ではない。基準に同期している間は小さく保たれ、基準を失って手元の発振器だけで時刻を保つ間（**保持**）は、経過時間とともに増える（[D-33](DECISIONS.md)）。

## Level 3 — 空間

時間と同じく、位置も素の値ではない。

- **位置推定**（Position Estimate）: 位置の推定量。参照系は座標系、来歴は導出の経緯。
- 速度・姿勢・視線方向も、同じく推定量である。
- 観測者の位置・速度・姿勢の観測区間ごとの並びが **観測者の軌跡**（6DoF）になる（[D-03](DECISIONS.md)）。

## Level 4 — 信号

すべての観測内容は **信号** で表せる（[D-27](DECISIONS.md)）。

- 信号とは、**軸の組** の上に並んだ推定量である。軸の座標も推定量（Level 2・3）である。

| 軸の組 | 例 |
|--------|-----|
| 時間 | 電波の波形、気温の時系列、音響 |
| 空間 | 画像（2 次元） |
| 周波数 | スペクトル |
| 複数の軸（時間 × 周波数、時間 × 空間 など） | スペクトログラム、動画 |

- 種類を増やすのではなく、軸の組で区別する。時間周波数解析の経験（AudioTrace）がそのまま生きる層である。

## Level 5 — 観測

ここで初めて、世界と認識が接する。

**Observation ＝ 観測者 ＋ センサー ＋ 観測区間 ＋ 観測者の位置・姿勢 ＋ 信号**  
（加えて、センサーの状態と信頼の根拠を持つ）

- 例: カメラ A が、2027-01-01T00:00:00Z からの観測区間に、ある位置・姿勢で、画像（空間の信号）を得た。
- **観測の内容は真実ではない。しかし、観測したという出来事は事実である**（[D-28](DECISIONS.md)）。事実は S4 が不変に記録し、内容から世界を推定するのは S5・S6 である。
- 校正も環境も観測である（[D-05](DECISIONS.md)、[D-20](DECISIONS.md)）。シミュレーションは模型世界の観測である（[D-31](DECISIONS.md)）。

## Level 6 — 来歴

ここから Reality Traceability になる（[D-29](DECISIONS.md)）。

| 要素 | 内容 |
|------|------|
| 節点：Observation | グラフの根。不変 |
| 節点：Measurement | 観測から取り出した推定量（例: 明るさ 12.34 ± 0.015 等級、位置 …） |
| 節点：Claim | 主張（Level 7 で中身が決まる） |
| 辺：Transformation | 入力の節点 × 手法の版 × パラメータ → 出力の節点 |

- 例: 生画像 → ダーク補正 → フラット補正 → 測光。どの段も Transformation である。観測から測定を取り出すことも変換である。
- Transformation は段ではなく **矢印** である。各辺は前提（観測の型、S5）を確かめ、不確かさを伝播させる。
- **Proof** は、Claim から根の Observation まで遡る **祖先の部分グラフ** と、その各辺の前提の充足である。

```text
Claim
 ← Measurement …（Transformation の連鎖）
 ← Observation（根・事実）
 ⇠ Event（推定。グラフの外の世界）
```

- Proof が保証するのは **手続きの正当性** であって、世界についての真理ではない。
- グラフの要素は **節点**、観測拠点は **ノード** と呼び分ける。

## Level 7 — 科学

ここで初めて、測光・掩蔽・流星・電波天文などの分野が登場する。

- どの分野も、**信号処理 → 推定 → 主張** という同じ形をしている。分野の違いは手法の違いであって、モデルの違いではない（[D-10](DECISIONS.md)）。
- 主張の種類は、測定 Claim・同定 Claim・合成 Claim（[S6](scopes/S6-claim-verification.md)）。事象の存在の主張（「これらの観測は一つの事象による」）もここに含まれる。
- 例: この星は明るくなった／この小惑星はここにある／この衛星の軌道はこうである。

## Level 8 — 知識

最上位で、Claim 同士がつながる（[D-30](DECISIONS.md)）。

- **Theory** は、複数の Claim を説明し、まだ観測されていない事象を **予測** する仮説である。
  - 例: Claim A「この星は暗くなった」、Claim B「表面活動が増加した」、Claim C「周期変動がある」を説明する Theory。
- Theory は Proof を持たない。Claim との間に **支持** と **反証** の関係を持つ。
- Theory を立てる主体は人間であり、機械は候補の提示までにとどめる（[S8](scopes/S8-human-discovery.md)）。

## 全体は循環する

```text
世界（Event）
   ⇣ 観測
Observation ──Transformation──▶ Measurement ──Transformation──▶ Claim
                                                                  ⇣ 支持・反証
                                                               Theory
   ⇡ 予測 → 観測依頼（S7）                                        │
   └──────────────────────────────────────────────────────────────┘
```

知識は一方向の頂点ではない。Theory の予測が観測依頼になり、新しい観測が Claim を生み、Theory を支持または反証する。

## 拡張性

天文学は最初の実験分野である（[D-22](DECISIONS.md)）。Level 0〜6 は分野に依存しないので、次のものも同じ哲学で入る。違うのは Level 7 の手法だけである。

- 音響（AudioTrace）、気象観測、FPGA による計測、IoT センサー、生体信号
- シミュレーションの結果（例: Project Genesis）。模型世界の観測として扱う
