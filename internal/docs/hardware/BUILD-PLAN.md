# BUILD-PLAN — 観測機材の自作計画

光学・電波観測機材を **自作できるところの極限まで** 作るための計画。機材の考え方（モジュール契約・機材ファミリー）は [HARDWARE](../HARDWARE.md)、部品・方式の選定は [tech/](../tech/INDEX.md) を正本とする。

---

## 1. 進め方：基準機と置き換え

```text
基準機（市販モジュールの組み合わせ）を動かす
   ↓
モジュールを一つ自作品に置き換える
   ↓
基準機と同時に観測し、出力を比べる（差＝自作モジュールの不確かさの実測）
   ↓
比較の記録を、自作モジュールの信頼の根拠として残す
   ↓
次のモジュールへ
```

- 置き換えはモジュール契約の上での差し替えなので、観測系は常に動き続ける（[D-32](../DECISIONS.md)）。
- 基準機は置き換え後も残し、比較の相手として使い続ける。

## 2. 自作の範囲

| 系統 | 自作する | 買う（自作の限界） |
|------|----------|--------------------|
| 時刻 | 発振器を基準に合わせる仕組み、FPGA でのタイムスタンプ、保持の制御 | GNSS 受信モジュール |
| 光学 | センサー基板、FPGA 読み出し、冷却と温度制御、筐体、架台。主鏡は研磨で作れる | イメージセンサーのチップ、レンズのガラス |
| 電波 | アンテナ、低雑音増幅器、フィルター、周波数変換、ADC と FPGA による受信機 | 個々の半導体部品 |

## 3. 順番

| 順 | 機材 | 基準機 | 自作で置き換える順 |
|----|------|--------|--------------------|
| 1 | **時刻モジュール** | GNSS モジュールの時刻パルスを計算機で受ける | FPGA タイムスタンプ → 発振器の同期と保持 → 誤差の補正 |
| 2 | **流星電波** | 自作八木アンテナ＋市販の受信機（SDR） | 低雑音増幅器 → フィルター → FPGA 受信機 |
| 3 | **全天カメラ** | 市販の高感度カメラモジュール＋魚眼レンズ＋小型計算機 | 露光タイミングの取り出し → センサー基板と FPGA 読み出し → 冷却 |
| 4 | **21cm 水素線** | 自作ホーン＋市販の低雑音増幅器＋受信機 | 低雑音増幅器 → 周波数変換 → FPGA 受信機（流星電波で作ったものを発展） |
| 5 | **太陽電波** | 衛星放送用パラボラと変換器の流用 | 給電部 → 受信系 |
| 6 | **測光カメラ** | 小型望遠鏡＋架台＋市販の冷却カメラ | 架台 → カメラ（全天カメラで作った読み出しと冷却を発展）→ 主鏡 |

- 時刻モジュールが最初なのは、全機材に共通の起点だからである（[D-18](../DECISIONS.md)）。2 以降の機材はすべて、このモジュールの時刻を使う。
- 2 と 3 は同じ事象（流星）を光と電波で捉える組であり、クロスモーダル連動（S3）の最初の実証になる。
- 後の機材ほど、前の機材で作ったモジュール（受信機・読み出し・冷却）を発展させて使う。

## 4. 予算の目安

価格は変動するため概算。基準機の段階の目安を示す。

| 機材 | 目安 |
|------|------|
| 時刻モジュール | 1〜2.5 万円（FPGA ボードは手持ちを使う） |
| 流星電波 | 1.5〜3 万円 |
| 全天カメラ | 3〜5 万円 |
| 21cm 水素線 | 2〜4 万円（向きを変える架台は別） |
| 太陽電波 | 1〜2 万円 |
| 測光一式 | 10〜40 万円以上 |

自作に置き換える段階の目安: 基板の発注は 1 枚数千円から、受信機 2〜5 万円、カメラ基板 3〜6 万円、主鏡の研磨キット 2〜4 万円。  
順 1〜3 の基準機と時刻の自作までで、合計 6〜10 万円程度を見込む。

## 5. 守ること

- 受信のみとし、送信はしない（送信には無線の免許が要る）。
- 機材ごとに、モジュール契約の四要素（制御経路・データ経路・信頼の根拠の宣言・設計の版への参照）を記録する（[HARDWARE](../HARDWARE.md)）。
- 市販モジュールの内部処理や遅延で分からない部分は、分からないまま宣言する。分からない部分が、次に自作で置き換える候補になる。
