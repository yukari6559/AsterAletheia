# TIMING-MODULE — 時刻モジュールの要求と段階

全機材に共通の信頼の起点となる時刻モジュールの正本（[D-18](../DECISIONS.md)、[HARDWARE](../HARDWARE.md)）。  
ここでは **何を満たすべきか** だけを技術中立に定める。部品・方式の選定は [tech/](../tech/INDEX.md) に残す。

---

## 1. 出すもの

時刻モジュールの出力は、時刻ではなく **観測時刻（時刻の推定量）** である（[ONTOLOGY Level 1・2](../ONTOLOGY.md)）。

| 推定量の構成 | 時刻モジュールが与えるもの |
|--------------|----------------------------|
| 値 | 事象（露光の開始・終了、サンプルの区切りなど）が起きた時刻 |
| 不確かさ | その時点での時刻の不確かさ（同期中と保持中で変わる） |
| 確信度 | 不確かさの見積もりの根拠の強さ（基準の種類、同期状態、遅延が既知か） |
| 参照系 | 時刻系（どの時刻系に対する値か） |
| 来歴 | 基準の種類、同期状態、受信状態、モジュールの設計の版 |

## 2. 要求

| ID | 要求 |
|----|------|
| T-R1 | 外部の基準（GNSS など）に同期した時刻を保つ |
| T-R2 | 他の機材からの事象の信号（露光の開始・終了など）に、時刻の推定量を付ける |
| T-R3 | 同期状態（同期中・保持中・未同期）と、その時点の不確かさを常に報告する |
| T-R4 | 基準を失っても時刻を保ち、保持中は経過時間に応じて不確かさを増やして報告する（[D-33](../DECISIONS.md)） |
| T-R5 | 同じ拠点の複数の機材が共有できる（拠点内の信号が同じ時刻の根拠を持つ） |
| T-R6 | モジュール契約（制御経路・データ経路・信頼の根拠の宣言・設計の版への参照）に従う |
| T-R7 | 計算機の処理遅延に左右されない（時刻は計算機に届く前に付ける） |

## 3. 不確かさの出どころ

時刻の不確かさは、次の項の合成として見積もる。自作で置き換えるほど、各項が「分からない」から「分かる」へ変わる。

| 項 | 内容 |
|----|------|
| 基準の誤差 | 基準の時刻パルスそのものの誤差 |
| 刻みの粗さ | 時刻を数える刻みの細かさで決まる誤差 |
| 発振器のふらつき | 基準と基準の間で、手元の発振器がずれる量 |
| 経路の遅延 | アンテナ線・信号線・入力回路を通る遅延 |
| 相手機材の遅延 | 機材が事象の信号を出すまでの内部の遅延（市販品では分からないことが多い） |
| 保持中の増加 | 基準を失ってからの経過時間に応じて増える分 |

## 4. 段階

| 段階 | 内容 | 不確かさの目安 | 主に分かるようになる項 |
|------|------|----------------|------------------------|
| **T0** 基準機 | 基準の時刻パルスを計算機で受け、計算機の時計で時刻を付ける | ミリ秒級（計算機の遅延が分からない） | ― |
| **T1** FPGA タイムスタンプ | 基準の時刻パルスと事象の信号を FPGA で直接数える | 100 ナノ秒級 | 刻みの粗さ、入力回路の遅延 |
| **T2** 発振器の同期と保持 | より安定な発振器を基準に合わせ、基準を失っても保つ | 保持中の増加が小さくなる | 発振器のふらつき、保持中の増加 |
| **T3** 誤差の補正 | 基準の誤差の補正、経路の遅延の校正、複数の基準どうしの比較 | 10 ナノ秒級 | 基準の誤差、経路の遅延 |

- 目標水準は「個人がナノ秒〜マイクロ秒級の時刻情報を、根拠付きで扱える状態」（[D-18](../DECISIONS.md)）。T1 でマイクロ秒より十分小さくなり、T3 でナノ秒級に近づく。
- T0 は T1 以降の比較の相手として残す（[D-32](../DECISIONS.md)）。

## 5. 各段階の完了条件

| 段階 | 完了条件 |
|------|----------|
| T0 | 基準の時刻パルスを受け、同期状態とともに記録できる。計算機の遅延は「不明」と宣言される |
| T1 | 基準の時刻パルスと外部の信号に FPGA で時刻を付け、T0 と同時に記録して差を比べられる。刻みと入力回路の遅延が文書化される |
| T2 | 基準を意図的に外したときの時刻のずれを測り、保持中の不確かさの増え方として報告できる |
| T3 | 補正前後の差と、経路の遅延の校正値が記録される |
